## What's new / 更新內容

**繁體中文**
- **遠端主機**（#32）：在「設定 → 遠端主機」加入一台能用 SSH 登入的 Linux 主機（x86_64、ARM64），主機上 agent 的速度和歷史會和這台電腦的一起顯示，也能只看某一台主機。
  - 連線使用你自己的 SSH 設定與金鑰，Agent Speed 不會儲存或詢問密碼。
  - 主機的 `~/.cache/agent-speed` 會放一個唯讀的小程式，只傳回 token 數、時間、模型與專案名稱等數字，絕不傳送對話內容。
- **每個來源可以讀取多個資料夾**（#45）：在「設定 → 資料來源」為同一個工具加入多個位置，例如不同版本各自寫入的資料夾；預設位置也可以移除。所有位置一起讀取，同一份紀錄只計算一次。
- **新增 Devin CLI 來源**：以唯讀方式讀取 Devin CLI 的工作階段資料庫，目前共支援 18 種來源。Devin Desktop 尚不支援。
- **看板閒置時淡出**：看板也可以開啟「閒置時淡出」，閒置 60 秒後變淡（新看板預設關閉）。
- **懸浮窗大小**：大小選單新增滑桿，每種樣式都能在 64–240 pt 之間調整。
- **Windows 工作列**：工作列上的速度顯示會避開其他程式放在工作列上的視窗，例如 TrafficMonitor，不再互相重疊。
- **價格表**：新增 Kimi K3.1 Pro 與 K3.1 Pro HighSpeed，並補上幾個 Kimi 模型的別名。

**修正**
- **Windows 懸浮窗**：拖曳時不再落後滑鼠（高回報率的滑鼠以前會落後將近一秒），顯示卡滿載時介面也不再卡住（#37）。
- **macOS 螢幕亮度**：部分 Mac 開著懸浮窗時，內建螢幕的亮度調不動。懸浮窗和看板現在預設與螢幕更新同步，「設定 → 特效」也新增了對應的開關（#48）。
- **Grok Build 思考 token**：自訂模型另外回報的思考 token 現在會計入速度。更新後用量歷史會重新分析一次，舊紀錄也會補上（#51）。
- **Grok Build 工具結束後**：工具執行完、模型繼續工作時，狀態會立刻回到「產生中」（#52）。

**简体中文**
- **远程主机**（#32）：在「设置 → 远程主机」添加一台能用 SSH 登录的 Linux 主机（x86_64、ARM64），主机上 agent 的速度和历史会和这台电脑的一起显示，也能只看某一台主机。
  - 连接使用你自己的 SSH 配置与密钥，Agent Speed 不会保存或询问密码。
  - 主机的 `~/.cache/agent-speed` 会放一个只读的小程序，只传回 token 数、时间、模型与项目名称等数字，绝不传送对话内容。
- **每个来源可以读取多个文件夹**（#45）：在「设置 → 数据来源」为同一个工具添加多个位置，例如不同版本各自写入的文件夹；默认位置也可以移除。所有位置一起读取，同一份记录只计算一次。
- **新增 Devin CLI 来源**：以只读方式读取 Devin CLI 的会话数据库，目前共支持 18 种来源。Devin Desktop 暂不支持。
- **看板空闲时淡出**：看板也可以开启「空闲时淡出」，空闲 60 秒后变淡（新看板默认关闭）。
- **悬浮窗大小**：大小菜单新增滑块，每种样式都能在 64–240 pt 之间调整。
- **Windows 任务栏**：任务栏上的速度显示会避开其他程序放在任务栏上的窗口，例如 TrafficMonitor，不再互相重叠。
- **价格表**：新增 Kimi K3.1 Pro 与 K3.1 Pro HighSpeed，并补上几个 Kimi 模型的别名。

**修复**
- **Windows 悬浮窗**：拖动时不再落后鼠标（高回报率的鼠标以前会落后将近一秒），显卡满载时界面也不再卡住（#37）。
- **macOS 屏幕亮度**：部分 Mac 开着悬浮窗时，内建屏幕的亮度调不动。悬浮窗和看板现在默认与屏幕刷新同步，「设置 → 特效」也新增了对应的开关（#48）。
- **Grok Build 思考 token**：自定义模型另外回报的思考 token 现在会计入速度。更新后用量历史会重新分析一次，旧记录也会补上（#51）。
- **Grok Build 工具结束后**：工具执行完、模型继续工作时，状态会立刻回到「生成中」（#52）。

**English**
- **Remote hosts** (#32). Add a Linux machine you can reach with SSH (x86_64, ARM64) in Settings → Remote Hosts, and the speed and history of its agents appear next to this computer's, or on their own.
  - Your own SSH configuration and keys are used; Agent Speed never stores or asks for a password.
  - A small read-only helper is placed in `~/.cache/agent-speed` on the host. Only numbers come back (token counts, times, model and project names), never conversation content.
- **Several folders per source** (#45). In Settings → Data Sources, a tool can read several locations, for example the folders that two builds of it write to; the default location can be removed too. All locations are read together, and each record counts once.
- **Devin CLI source.** Agent Speed now reads Devin CLI's session database, read-only, for 18 supported sources in all. Devin Desktop is not supported yet.
- **Boards fade when idle.** A board can now fade after 60 seconds idle, as an orb can (off for a new board).
- **Orb size.** The Size menu has a slider, and every style goes from 64 to 240 pt.
- **Windows taskbar.** The taskbar readout keeps clear of other apps' windows on the taskbar, such as TrafficMonitor, instead of overlapping them.
- **Prices.** Kimi K3.1 Pro and K3.1 Pro HighSpeed are priced, and a few Kimi model aliases are recognized.

**Fixes**
- **Windows orbs.** A dragged orb no longer trails the pointer (a high-rate mouse used to leave it almost a second behind), and the interface no longer stalls while the graphics card is saturated (#37).
- **macOS display brightness.** On some Macs the built-in display's brightness could not change while orbs were shown. Orbs and boards now follow the display's refresh by default, with a switch in Settings → Effects (#48).
- **Grok Build thinking tokens.** Thinking tokens a custom model reports separately now count toward speed. The history is analysed once after the update, so older records are corrected too (#51).
- **Grok Build after a tool.** When a tool finishes and the model carries on, the state returns to generating straight away (#52).

**日本語**
- **リモートホスト**（#32）：「設定 → リモートホスト」で SSH で接続できる Linux マシン（x86_64、ARM64）を追加すると、そのマシンのエージェントの速度と履歴がこのコンピュータのものと並んで表示されます。ホストごとの表示もできます。
  - 接続にはご自身の SSH 設定と鍵を使います。Agent Speed がパスワードを保存したり尋ねたりすることはありません。
  - ホストの `~/.cache/agent-speed` に読み取り専用の小さなプログラムを置きます。返ってくるのはトークン数、時刻、モデル名、プロジェクト名などの数値だけで、会話の内容は送られません。
- **ソースごとに複数のフォルダ**（#45）：「設定 → データソース」で、同じツールに複数の場所を追加できます（たとえば別々のビルドが書き込むフォルダ）。既定の場所も削除できます。すべての場所をまとめて読み取り、同じ記録は一度だけ数えます。
- **Devin CLI に対応**：Devin CLI のセッションデータベースを読み取り専用で読み取ります。対応ソースは合計 18 種類です。Devin Desktop にはまだ対応していません。
- **ボードも待機中は薄く**：ボードでも「待機中は薄くする」を有効にでき、60 秒待機すると薄くなります（新しいボードは既定でオフ）。
- **オーブのサイズ**：サイズメニューにスライダーを追加し、どのスタイルも 64〜240 pt で調整できます。
- **Windows のタスクバー**：タスクバーの速度表示は、TrafficMonitor など他のアプリがタスクバーに置いたウィンドウを避け、重ならなくなりました。
- **価格表**：Kimi K3.1 Pro と K3.1 Pro HighSpeed を追加し、Kimi のモデル別名をいくつか補いました。

**修正**
- **Windows のオーブ**：ドラッグ中にポインタから遅れなくなりました（レポートレートの高いマウスでは 1 秒近く遅れていました）。グラフィックカードが高負荷のときに画面が止まることもなくなりました（#37）。
- **macOS の画面の明るさ**：一部の Mac で、オーブを表示している間は内蔵ディスプレイの明るさを変えられませんでした。オーブとボードは既定で画面のリフレッシュに同期するようになり、「設定 → エフェクト」に切り替えスイッチを追加しました（#48）。
- **Grok Build の思考トークン**：カスタムモデルが別に報告する思考トークンも速度に含めるようになりました。更新後に使用履歴を一度再分析し、過去の記録も修正します（#51）。
- **Grok Build のツール終了後**：ツールが終わってモデルが作業を続けると、状態がすぐに生成中に戻ります（#52）。
