## What's new / 更新內容

**繁體中文**
- **額度**：在下拉面板的「來源」可以看到各 agent 訂閱方案的額度，例如 5 小時、每週、單一模型每週各用了多少、什麼時候重置。AI 娘旁邊也多了一張額度卡，只列出正在執行、而且已登入的 agent。macOS、Windows、Linux 都支援。
  - **Codex、Claude Desktop**：直接讀本機資料，預設開啟。
  - **Claude Code**：到「設定 → 資料來源」打開「透過狀態列顯示 Claude Code 額度」，打開前會先徵求你的同意；關掉就還原原本的狀態列。Agent Speed 不會讀取或傳送 Claude 的登入憑證。
  - **Grok Build、Devin、Antigravity、Kimi Code、Gemini CLI、Factory Droid**：使用各 agent 自己的登入或本機資料，預設開啟。**ZCode** 要在設定裡輸入金鑰；**Qoder、WorkBuddy** 要讀瀏覽器的登入狀態，預設關閉，打開前會先詢問。這幾家的介面沒有公開文件，數字若有出入請回報。
  - **遠端主機**：主機上 agent 的額度也會顯示，也可以替主機上的 Claude Code 打開狀態列額度。
- **額度上限估算**：依廠商回報的百分比和本機量到的花費（API 等值美元），推算每個週期的上限，額度沒用完也估得出來。面板顯示「已用金額 / ≈上限」和重置時間，滑鼠移上去可以看範圍、可信度和方案；廠商兩次更新之間，百分比會依本機的用量推算，前面加上「≈」。估算只在本機計算；連線回報服務時，可以用新的「額度」開關決定是否分享。分享的內容不含帳號 ID 或電子郵件，只用一個匿名代號分辨同一個 agent 的不同帳號。Claude Desktop 本身不提供方案名稱，改依額度推算（沒有 5 小時週期的是 Ultra），面板會標示「依額度推算」。
- **AI 娘**：
  - 性能卡新增「首字」（等到第一個字的時間）：10 秒內綠色、10–14 秒黃色、15 秒以上紅色。
  - 新的模型卡：列出正在執行的模型和各自的速度。
  - 費用卡新增今日總費用：工作時顯示即時和今日兩行，停下後只留今日那行。
  - 左右兩側的卡片會自動平衡，不再全部擠在同一邊。
  - 伸懶腰、打呵欠、踮腳尖、屈膝禮不再把角色明顯拉長或壓扁。
- **新來源：Qoder IDE 與 Qoder CLI**（#47），國際版和國內版都包括。
  - **Qoder IDE**：讀取 IDE 本機的對話資料庫（只讀），每次模型呼叫都有 Qoder 回報的真實 token，所以看得到速度、用量和工作階段。Qoder 沒有記錄請求的開始時間，耗時從上一筆紀錄算起，速度會比模型實際的略低；Qoder 只記錄選用的檔位（Auto、Lite 等），不記實際模型，所以費用顯示「–」。
  - **Qoder CLI**（`qodercli`、國內版 `qoderclicn`，新的 Qoder 桌面 App 也寫在同一處）：使用 Qoder 自家的模型時，Qoder 不會把 token 存到本機，只看得到工作階段和狀態。以 `QODER_EXPOSE_TOKEN_USAGE=1`（國內版 `QODERCN_EXPOSE_TOKEN_USAGE=1`）啟動，或使用自訂模型，才會有 token 和速度。
- **價格**：Grok Build 的 `grok-4.7-build` 等型號依 xAI 官方 API 價格計費（#60）；Claude Fable 5.2 與 Mythos 5.2 依 Anthropic 官方價格計費。價格表每天自動更新，舊版本也已生效。
- **效能**：macOS 的 AI 娘樣式大幅降低 CPU 用量；同時監看大量對話紀錄時也更省 CPU。

**修正**
- **Claude Desktop 額度**：Desktop 視窗退到背景一段時間後，額度不再從 AI 娘旁邊消失。
- **macOS 右鍵選單**：把懸浮窗拖到另一台螢幕後，右鍵選單有時再也不出現，懸浮窗甚至會消失，必須重開 App 才恢復。現在選單不再掛在懸浮窗上，任何螢幕都能正常打開，懸浮窗也不會被帶走。選單靠近螢幕邊緣時會往上、往左移，完整顯示。
- **macOS 拖動懸浮窗**：第一次按下拖動有時沒反應，要按第二次才拖得動。現在第一次就能拖。
- **macOS 歷史視窗**：工具列的選擇器不再擠在一起。

**English**
- **Quotas**: the dropdown's Sources section shows each agent's subscription limits — how much of the 5-hour, weekly and per-model weekly windows is used and when each resets. The character orb gains a quota card listing the agents that run and are signed in. On macOS, Windows and Linux.
  - **Codex, Claude Desktop**: read from local data, on by default.
  - **Claude Code**: turn on "Show Claude Code quota through its status line" in Settings → Data Sources; Agent Speed asks before it changes anything, and turning it off restores your status line. Agent Speed never reads or sends Claude sign-in credentials.
  - **Grok Build, Devin, Antigravity, Kimi Code, Gemini CLI, Factory Droid**: through each agent's own sign-in or local data, on by default. **ZCode** needs a key entered in Settings; **Qoder and WorkBuddy** read your browser's session, off by default and asked before they start. These vendors don't document these interfaces, so please report numbers that look off.
  - **Remote hosts**: agents on your hosts show their quotas too, and the Claude Code status line can be turned on for a host.
- **Quota cap estimates**: from the vendor's percent and the spend Agent Speed measures (in API-equivalent US dollars), each window's cap is estimated, even when you never use it up. The Sources rows show "used / ≈cap" with the reset, and the tooltip shows the range, confidence and plan; between two vendor updates the percent is extrapolated from local usage and marked with "≈". Estimates are computed on your computer only; with a reporting service, the new "Quotas" switch decides whether they are shared: never with an account id or e-mail address, only an anonymous tag that tells one agent's accounts apart. Claude Desktop names no plan, so its plan is inferred from the quota (no 5-hour window means Ultra) and marked "inferred from the quota".
- **Character orb**:
  - The performance card gains first-token latency, green under 10 s, amber 10–14 s, red from 15 s.
  - A new models card lists the running models with their speeds.
  - The cost card gains today's total: live rate and today while she works, only today once she rests.
  - Cards balance between her two sides instead of piling up on one.
  - Stretching, yawning, tiptoeing and the curtsy no longer visibly stretch or squash her.
- **New sources: Qoder IDE and Qoder CLI** (#47), international and China editions.
  - **Qoder IDE**: Agent Speed reads the IDE's local chat database (read-only), which holds the tokens Qoder reported for every model call, so speed, usage and sessions show. Qoder stores no request start, so a call is timed from the previous record and speeds read a little lower than the model's; it records only the tier you chose (Auto, Lite, …), not the model, so cost shows "–".
  - **Qoder CLI** (`qodercli`, the China edition's `qoderclicn`; the new Qoder desktop app writes to the same place): with Qoder's own models, Qoder keeps no token usage on disk, so only sessions and status show. Start it with `QODER_EXPOSE_TOKEN_USAGE=1` (China edition: `QODERCN_EXPOSE_TOKEN_USAGE=1`), or use a custom model, to get tokens and speed.
- **Prices**: Grok Build's `grok-4.7-build` and its siblings are priced as xAI's API models (#60); Claude Fable 5.2 and Mythos 5.2 at Anthropic's official prices. The price table updates itself daily, so earlier versions already have them.
- **Performance**: the character orb uses far less CPU on macOS, and watching many transcripts costs less CPU.

**Fixes**
- **Claude Desktop quota**: no longer drops off the character orb's card after Desktop's window has sat in the background for a while.
- **macOS right-click menu**: after an orb was dragged to another display, its right-click menu could stop appearing, and the orb could even disappear until the app restarted. Menus are no longer attached to the orb, so they open on every display and never take the orb with them. Near a screen edge a menu moves up and left to show whole.
- **macOS orb dragging**: the first press sometimes did not start a drag, and only a second one did. The first press drags now.
- **macOS history window**: the toolbar's pickers no longer crowd each other.

**日本語**
- **利用枠**：ドロップダウンの「ソース」で、各 agent のサブスクリプションの利用枠（5 時間、週、モデル別の週）をどれだけ使ったか、いつリセットされるかが分かります。キャラクターのオーブには、実行中でサインイン済みの agent を並べる利用枠カードが加わりました。macOS、Windows、Linux に対応しています。
  - **Codex、Claude Desktop**：ローカルのデータを読み取ります。初期設定でオンです。
  - **Claude Code**：「設定 → データソース」で「ステータスラインで Claude Code の利用枠を表示」をオンにしてください。変更する前に確認を求め、オフにすると元のステータスラインに戻ります。Agent Speed は Claude のサインイン情報を読み取ることも送信することもありません。
  - **Grok Build、Devin、Antigravity、Kimi Code、Gemini CLI、Factory Droid**：各 agent 自身のサインインやローカルのデータを使います。初期設定でオンです。**ZCode** は設定でキーの入力が必要です。**Qoder と WorkBuddy** はブラウザのセッションを読むため初期設定でオフで、オンにする前に確認します。これらのインターフェースは公開されていないため、数値がおかしい場合はお知らせください。
  - **リモートホスト**：ホスト上の agent の利用枠も表示され、ホストの Claude Code でステータスラインの利用枠をオンにすることもできます。
- **利用枠の上限の推定**：ベンダーが報告する割合と、Agent Speed が計測した費用（API 換算の米ドル）から、使い切っていない期間でも各期間の上限を推定します。「ソース」の行には「使用額 / ≈上限」とリセット時刻を表示し、ツールチップでは範囲、信頼度、プランを確認できます。ベンダーの更新の合間は、ローカルの使用量から割合を推定し「≈」を付けます。推定はお使いのコンピューターの中だけで計算します。レポートサービスを使う場合は、新しい「利用枠」スイッチで共有するかどうかを選べます。共有内容にアカウント ID やメールアドレスは含まれず、同じ agent の複数アカウントを見分ける匿名のタグだけを送ります。Claude Desktop はプラン名を提供しないため、利用枠から推定し（5 時間の期間がなければ Ultra）、「利用枠から推定」と表示します。
- **キャラクター**：
  - 性能カードに「初回」（最初の文字が出るまでの時間）が加わりました。10 秒未満は緑、10〜14 秒は黄、15 秒以上は赤です。
  - 新しいモデルカードに、実行中のモデルとそれぞれの速度が並びます。
  - 費用カードに本日の合計が加わりました。作業中はリアルタイムと本日の 2 行、止まると本日の行だけになります。
  - 左右のカードが自動で釣り合い、片側に偏らなくなりました。
  - 伸び、あくび、つま先立ち、カーテシーでキャラクターが目立って伸びたり潰れたりしなくなりました。
- **新しいソース：Qoder IDE と Qoder CLI**（#47）。国際版と中国版の両方を含みます。
  - **Qoder IDE**：IDE のローカルのチャットデータベースを読み取り専用で読みます。モデル呼び出しごとに Qoder が報告した実際のトークン数があるため、速度・使用量・セッションが表示されます。Qoder はリクエストの開始時刻を記録しないため、所要時間は直前の記録から数え、速度はモデルの実際より少し低めに出ます。Qoder は選んだ段階（Auto、Lite など）だけを記録し、モデル名は記録しないため、費用は「–」と表示されます。
  - **Qoder CLI**（`qodercli`、中国版 `qoderclicn`。新しい Qoder デスクトップアプリも同じ場所に書き込みます）：Qoder 独自のモデルでは、Qoder がトークン使用量をローカルに保存しないため、セッションと状態だけが表示されます。トークンと速度を表示するには `QODER_EXPOSE_TOKEN_USAGE=1`（中国版は `QODERCN_EXPOSE_TOKEN_USAGE=1`）を付けて起動するか、カスタムモデルを使ってください。
- **価格**：Grok Build の `grok-4.7-build` などは xAI の API 価格で計算します（#60）。Claude Fable 5.2 と Mythos 5.2 は Anthropic の公式価格です。価格表は毎日自動で更新されるため、以前のバージョンにもすでに反映されています。
- **パフォーマンス**：macOS のキャラクタースタイルの CPU 使用量を大きく減らしました。多数の会話ログを監視するときの CPU 使用量も減りました。

**修正**
