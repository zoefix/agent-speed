## What's new / 更新內容

**繁體中文**
- **區域網路**：把即時速度顯示在自製的桌面螢幕、智慧家庭或腳本上。在「設定 → API」頂端切換到「區域網路」：
  - **讓裝置讀取**：開啟後，區網內的裝置帶上存取碼，就能用 HTTP（`/v1/live`）、WebSocket（`/v1/stream`）或 TCP 逐行讀取速度，全部共用一個連接埠（預設 7247）。裝置也能用 Bonjour 搜尋 `_agentspeed._tcp` 自動找到電腦。存取碼可以隨時重新產生，舊裝置會立刻中斷。
  - **主動送到裝置**：加入裝置的位址，速度一有變化，app 就用 UDP（也可以填廣播位址送給整個網路）或 HTTP POST 送過去。可以設一組金鑰，每份資料都會附上簽章，讓裝置確認資料來自你的電腦。
  - 送出的只有速度數字：輸出速度、估算比例、工作中的 session 數、一分鐘的速度曲線和這台電腦的名稱，不含對話內容、模型、專案、路徑或費用。只會送到區網內的位址，不經過代理伺服器；資料以明文傳送。整個功能預設關閉，也受網路總開關管理。
  - 給開發者的說明：[spec/LAN.md](https://github.com/zoefix/agent-speed/blob/main/spec/LAN.md)，附一支可以直接測試的 Python 工具。

**简体中文**
- **局域网**：把实时速度显示在自制的桌面屏幕、智能家居或脚本上。在“设置 → API”顶部切换到“局域网”：
  - **让设备读取**：开启后，局域网内的设备带上访问码，就能通过 HTTP（`/v1/live`）、WebSocket（`/v1/stream`）或 TCP 逐行读取速度，全部共用一个端口（默认 7247）。设备也能通过 Bonjour 搜索 `_agentspeed._tcp` 自动找到电脑。访问码可以随时重新生成，旧设备会立即断开。
  - **主动发送到设备**：添加设备的地址，速度一有变化，应用就通过 UDP（也可以填写广播地址发送给整个网络）或 HTTP POST 发送过去。可以设置一组密钥，每份数据都会附上签名，让设备确认数据来自你的电脑。
  - 发送的只有速度数字：输出速度、估算比例、工作中的 session 数、一分钟的速度曲线和这台电脑的名称，不含对话内容、模型、项目、路径或费用。只会发送到局域网内的地址，不经过代理服务器；数据以明文传输。整个功能默认关闭，也受网络总开关管理。
  - 开发者文档：[spec/LAN.md](https://github.com/zoefix/agent-speed/blob/main/spec/LAN.md)，附一个可以直接测试的 Python 工具。

**English**
- **Local network.** Show your live speed on a homemade desk display, a smart home hub or a script. In Settings → API, switch to Local Network at the top:
  - **Devices read.** When it is on, devices on your network that present the access key read the speed over HTTP (`/v1/live`), WebSocket (`/v1/stream`) or line-by-line TCP, all on one port (7247 by default). Devices can also find the computer by browsing Bonjour for `_agentspeed._tcp`. Regenerating the key disconnects old devices at once.
  - **Send to devices.** Add a device's address, and the app sends the speed as it changes, by UDP (a broadcast address reaches the whole network) or HTTP POST. With a key, every frame carries a signature, so the device can check it came from your computer.
  - Only speed numbers are sent: output speed, its estimated share, working sessions, a one-minute speed history and this computer's name — never conversation content, models, projects, paths or costs. Only to local network addresses, never through a proxy; frames travel as plain text. The feature is off by default and follows the network master switch.
  - For developers: [spec/LAN.md](https://github.com/zoefix/agent-speed/blob/main/spec/LAN.md), with a Python tool for testing.

**日本語**
- **ローカルネットワーク**：ライブ速度を自作のデスクディスプレイやスマートホーム、スクリプトに表示できます。「設定 → API」の上部で「ローカルネットワーク」に切り替えます。
  - **デバイスから読み取る**：オンにすると、アクセスキーを持つネットワーク内のデバイスが HTTP（`/v1/live`）、WebSocket（`/v1/stream`）、または 1 行ずつの TCP で速度を読み取れます。すべて 1 つのポート（既定 7247）を使います。デバイスは Bonjour で `_agentspeed._tcp` を検索してコンピュータを見つけることもできます。キーを再生成すると、古いデバイスはすぐに切断されます。
  - **デバイスへ送信**：デバイスのアドレスを追加すると、速度が変わるたびにアプリが UDP（ブロードキャストアドレスならネットワーク全体へ）または HTTP POST で送信します。キーを設定すると各データに署名が付き、デバイスはあなたのコンピュータから届いたことを確認できます。
  - 送るのは速度の数値だけです：出力速度、推定の割合、作業中のセッション数、1 分間の速度の推移、このコンピュータの名前。会話の内容、モデル、プロジェクト、パス、費用は含みません。送信先はローカルネットワーク内のアドレスに限られ、プロキシは使いません。データは平文で送られます。機能は既定でオフで、ネットワークのマスタースイッチに従います。
  - 開発者向け：[spec/LAN.md](https://github.com/zoefix/agent-speed/blob/main/spec/LAN.md)（テスト用の Python ツール付き）。
