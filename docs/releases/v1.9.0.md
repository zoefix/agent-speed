## What's new / 更新內容

**繁體中文**
- **選單列、工作列顯示額度**（#81）：macOS 選單列和 Windows 工作列的讀數旁，可以多一塊「額度」，顯示一個來源的前兩個額度週期（例如 5h 和 7d）。到「設定 → 選單列」（macOS）或「設定 → 工作列」（Windows）的「顯示額度」選擇來源，再選要顯示已用還是剩餘的百分比。用量達 95% 時變紅，超過 1 小時沒更新的數字會變淡；游標停在上面可以看到每個週期的百分比、重置時間和更新時間。
- **閒置時隱藏**（#64）：每個懸浮窗多了「閒置時隱藏」開關，預設關閉。打開後，閒置 60 秒懸浮窗就會淡出並離開螢幕，agent 一開始工作就回來。macOS、Windows、Linux 都支援。
- **新來源：CodeBuddy Code**（#62）：騰訊 CodeBuddy 的命令列工具。Agent Speed 只讀取它在本機的工作階段紀錄，看得到速度、首字時間和用量；遠端主機上的 CodeBuddy Code 也算。CodeBuddy IDE 和 IDE 外掛的對話不計入。
- **Claude Code 額度**：打開「透過狀態列顯示 Claude Code 額度」後，命令列帳號也會顯示單一模型的每週額度（例如 Fable 7d）。數字來自 Claude Code 自己存在本機設定檔裡的用量暫存，Agent Speed 只讀這一項，不讀登入憑證；遠端主機也支援。
- **Antigravity 額度**：Antigravity 桌面版 2.32.1 起換了語言伺服器的名稱，額度一度讀不到，現在恢復了。只開命令列 agy 時，改由 agy 自己的用量報告取得額度（agy 1.1.11 以上）；Agent Speed 不讀 agy 的登入資料。
- **Antigravity 的模型與思考強度**：Gemini 4 Neon 和 Hydrogen 的「Extra」思考強度（命令列叫 xhigh）現在認得出來（#78）；紀錄超過 1 MiB 的長對話，也認得出回應用的是哪個模型，不再顯示為未知（#77）。
- **回報服務**：服務要求時，每張額度卡會附上背後實際用掉的 token 數，並依模型分開。

**修正**
- **Windows 打開設定就閃退**（#72、#76）：1.8.0 從系統匣或懸浮窗的選單打開「設定」時，可能因為堆疊溢位而閃退。
- **Claude Code 停下後還顯示速度**（#61、#67）：請求因額度限制、過載或其他錯誤而被放棄時，不再繼續顯示估計速度；等待重試的那段時間也不顯示。
- **Claude 已完成的請求又跳回生成中**（#79）：Claude Code 重新寫入較舊的回應片段時，已經結束的請求不會再被當成還在生成。
- **Qoder 速度一直是 0**（#73）：Qoder 桌面 App 0.5.13 會把一次呼叫拆成好幾行寫入，以前量不到速度，現在量得到了。
- **較新的 Linux 連不上網**（#80）：在 Ubuntu 26.04、Debian 13、Fedora 42 等系統上，AppImage 版的所有 HTTPS 連線都會失敗，價格表、匯率、更新檢查和回報都受影響。現在改用系統的 OpenSSL，.deb 也會一併安裝它。
- **Linux 回報額度**：Linux 版連接回報服務時，額度現在會像 macOS、Windows 一樣送出。

**简体中文**
- **菜单栏、任务栏显示额度**（#81）：macOS 菜单栏和 Windows 任务栏的读数旁，可以多一块「额度」，显示一个来源的前两个额度周期（例如 5h 和 7d）。到「设置 → 菜单栏」（macOS）或「设置 → 任务栏」（Windows）的「显示额度」选择来源，再选显示已用还是剩余的百分比。用量达到 95% 时变红，超过 1 小时没有更新的数字会变淡；鼠标停在上面可以查看每个周期的百分比、重置时间和更新时间。
- **空闲时隐藏**（#64）：每个悬浮窗新增「空闲时隐藏」开关，默认关闭。打开后，空闲 60 秒悬浮窗就会淡出并离开屏幕，agent 一开始工作就回来。macOS、Windows、Linux 都支持。
- **新来源：CodeBuddy Code**（#62）：腾讯 CodeBuddy 的命令行工具。Agent Speed 只读取它在本机的会话记录，能看到速度、首字时间和用量；远程主机上的 CodeBuddy Code 也计入。CodeBuddy IDE 和 IDE 插件的对话不计入。
- **Claude Code 额度**：打开「通过状态栏显示 Claude Code 额度」后，命令行账号也会显示单一模型的每周额度（例如 Fable 7d）。数字来自 Claude Code 自己保存在本机配置文件里的用量缓存，Agent Speed 只读这一项，不读登录凭证；远程主机也支持。
- **Antigravity 额度**：Antigravity 桌面版 2.32.1 起更换了语言服务器的名称，额度一度读不到，现在恢复了。只开命令行 agy 时，改由 agy 自己的用量报告获取额度（agy 1.1.11 以上）；Agent Speed 不读取 agy 的登录数据。
- **Antigravity 的模型与思考强度**：Gemini 4 Neon 和 Hydrogen 的「Extra」思考强度（命令行叫 xhigh）现在能识别了（#78）；记录超过 1 MiB 的长对话，也能识别回应使用的模型，不再显示为未知（#77）。
- **上报服务**：服务需要时，每张额度卡会附上背后实际消耗的 token 数，并按模型分开。

**修复**
- **Windows 打开设置就崩溃**（#72、#76）：1.8.0 从托盘或悬浮窗的菜单打开「设置」时，可能因栈溢出而崩溃。
- **Claude Code 停下后仍显示速度**（#61、#67）：请求因额度限制、过载或其他错误而被放弃时，不再继续显示估计速度；等待重试的那段时间也不显示。
- **Claude 已完成的请求又跳回生成中**（#79）：Claude Code 重新写入较旧的回应片段时，已经结束的请求不会再被当成还在生成。
- **Qoder 速度一直是 0**（#73）：Qoder 桌面 App 0.5.13 会把一次调用拆成好几行写入，以前测不到速度，现在可以测到了。
- **较新的 Linux 无法联网**（#80）：在 Ubuntu 26.04、Debian 13、Fedora 42 等系统上，AppImage 版的所有 HTTPS 连接都会失败，价格表、汇率、更新检查和上报都受影响。现在改用系统的 OpenSSL，.deb 也会一并安装它。
- **Linux 上报额度**：Linux 版连接上报服务时，额度现在会像 macOS、Windows 一样发送。

**English**
- **Quota on the menu bar and taskbar** (#81): next to the readout in the macOS menu bar and on the Windows taskbar, a Quota block can show one source's first two quota windows (such as 5h and 7d). Pick the source under Show quota in Settings → Menu Bar (macOS) or Settings → Taskbar (Windows), and whether the percents are used or remaining. A window turns red at 95% used, a number more than an hour old turns pale, and hovering shows every window's percent, reset time and update time.
- **Hide when idle** (#64): each orb has a new Hide when idle switch, off by default. With it on, an orb that has been idle for 60 seconds fades out and leaves the screen, and comes back as soon as an agent starts working. On macOS, Windows and Linux.
- **New source: CodeBuddy Code** (#62): Tencent CodeBuddy's command-line tool. Agent Speed only reads its session logs on your computer for speed, first-token latency and usage, on remote hosts too. The CodeBuddy IDE and its plugins are not counted.
- **Claude Code quota**: with "Show Claude Code quota through its status line" on, the command-line account also shows its per-model weekly limits (such as Fable 7d). They come from the usage cache Claude Code keeps in its own config file on your computer; Agent Speed reads only that entry, never sign-in credentials, and on remote hosts too.
- **Antigravity quota**: Antigravity's desktop app renamed its language server in 2.32.1, which stopped the quota; it shows again. When only the agy command line runs, the quota comes from agy's own usage report (agy 1.1.11 or later); Agent Speed never reads agy's sign-in.
- **Antigravity models and effort**: the Extra thinking level of Gemini 4 Neon and Hydrogen (xhigh on the command line) is recognized (#78), and long conversations whose records exceed 1 MiB keep the model that answered instead of showing it as unknown (#77).
- **Reporting services**: when a service asks, each quota card carries the tokens actually spent behind it, split by model.

**Fixes**
- **Windows Settings crash** (#72, #76): in 1.8.0, opening Settings from the tray or an orb's menu could crash with a stack overflow.
- **Claude Code showing speed after it stopped** (#61, #67): a request Claude Code gives up on after a rate limit, an overload or another error no longer leaves an estimated speed running, and neither does the wait for a retry.
- **A finished Claude request returning to generating** (#79): when Claude Code writes an older part of a response again, a request that has ended is no longer treated as still generating.
- **Qoder speed stuck at 0** (#73): Qoder's desktop app 0.5.13 writes one call as several lines, so its speed was never measured; it is now.
- **No network on newer Linux** (#80): on Ubuntu 26.04, Debian 13, Fedora 42 and similar systems, every HTTPS connection of the AppImage failed, so prices, exchange rates, update checks and reporting did not work. The packages now use the system's OpenSSL, and the .deb installs it.
- **Linux quota reporting**: connected to a reporting service, the Linux app now sends quotas as macOS and Windows do.

**日本語**
- **メニューバーとタスクバーに利用枠**（#81）：macOS のメニューバーと Windows のタスクバーの表示の横に「利用枠」ブロックを追加でき、1 つのソースの最初の 2 つの利用枠の期間（5h と 7d など）を表示します。「設定 → メニューバー」（macOS）または「設定 → タスクバー」（Windows）の「利用枠を表示」でソースを選び、割合を使用済みと残りのどちらで表示するかを選べます。使用量が 95% に達すると赤くなり、1 時間以上更新されていない数値は薄く表示されます。ポインタを合わせると、各期間の割合・リセット時刻・更新時刻を確認できます。
- **待機中は隠す**（#64）：各オーブに「待機中は隠す」スイッチが加わりました（初期設定はオフ）。オンにすると、60 秒待機したオーブはフェードアウトして画面から消え、agent が動き出すとすぐに戻ります。macOS、Windows、Linux に対応しています。
- **新しいソース：CodeBuddy Code**（#62）：Tencent CodeBuddy のコマンドラインツールです。Agent Speed はローカルのセッション記録だけを読み取り、速度・初回の時間・使用量を表示します。リモートホスト上の CodeBuddy Code も対象です。CodeBuddy IDE と IDE プラグインの会話は含まれません。
- **Claude Code の利用枠**：「ステータスラインで Claude Code の利用枠を表示」をオンにすると、コマンドラインのアカウントでもモデル別の週の利用枠（Fable 7d など）が表示されます。数値は Claude Code が自分の設定ファイルに保存している使用量のキャッシュから取り、Agent Speed はその項目だけを読み、サインイン情報は読みません。リモートホストにも対応しています。
- **Antigravity の利用枠**：Antigravity デスクトップ版 2.32.1 で言語サーバーの名前が変わり、利用枠が読めなくなっていましたが、再び表示されるようになりました。コマンドラインの agy だけを使っているときは、agy 自身の使用量レポートから利用枠を取得します（agy 1.1.11 以降）。Agent Speed は agy のサインイン情報を読みません。
- **Antigravity のモデルと思考レベル**：Gemini 4 Neon と Hydrogen の「Extra」の思考レベル（コマンドラインでは xhigh）を認識するようになりました（#78）。記録が 1 MiB を超える長い会話でも、応答したモデルが不明にならなくなりました（#77）。
- **レポートサービス**：サービスが求める場合、各利用枠カードに実際に使ったトークン数をモデル別に添えて送ります。

**修正**
- **Windows で設定を開くとクラッシュ**（#72、#76）：1.8.0 でトレイやオーブのメニューから「設定」を開くと、スタックオーバーフローでクラッシュすることがありました。
- **Claude Code が止まった後も速度を表示**（#61、#67）：レート制限、過負荷、その他のエラーで Claude Code が諦めたリクエストに推定速度が表示され続けることはなくなり、再試行を待つ間も表示しません。
- **完了した Claude のリクエストが生成中に戻る**（#79）：Claude Code が古い応答の一部をもう一度書き込んでも、終わったリクエストを生成中として扱わなくなりました。
- **Qoder の速度が 0 のまま**（#73）：Qoder デスクトップアプリ 0.5.13 は 1 回の呼び出しを複数の行に分けて書き込むため、速度を計測できていませんでした。計測できるようになりました。
- **新しい Linux でネットワークにつながらない**（#80）：Ubuntu 26.04、Debian 13、Fedora 42 などで AppImage 版の HTTPS 接続がすべて失敗し、価格表、為替レート、更新の確認、レポートが動きませんでした。システムの OpenSSL を使うようにし、.deb もそれを一緒にインストールします。
- **Linux の利用枠のレポート**：Linux 版がレポートサービスにつながっているとき、macOS や Windows と同じように利用枠を送るようになりました。
