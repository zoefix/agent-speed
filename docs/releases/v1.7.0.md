## What's new / 更新內容

**繁體中文**
- **AI 娘：新的懸浮窗樣式「角色」**，macOS、Windows、Linux 都能用。在懸浮窗按右鍵，選「樣式 → 角色」，桌面上就會站著一位 AI 娘跟著速度起舞：越快動作越大，還會換姿勢、轉身，身邊飄著她自己的花瓣或光點。
  - 共 17 位，每家模型一位：Claude、DeepSeek、Gemini、GLM、GPT、Grok、混元、JEV、Kimi、Llama、MiniMax、Mistral、Perplexity、Qwen、RWKV、Seed、文心。預設跟著這個懸浮窗目前最快的模型換人，也可以在右鍵「角色」固定一位。
  - 資訊卡片浮在她身旁，不會被她擋住：速度在右邊；性能與思考速度、網路速度、費用、今日用量與 agent 在左邊。每張卡片都能在右鍵「顯示資訊」或「設定 → 懸浮窗」開關；最快的模型名稱預設不顯示。
  - 切換到角色樣式時，會從 GitHub 依序自動下載全部角色（共約 160 MB），每一位都先核對大小與 SHA-256 才安裝。移除或取消的角色不會再自動下載；下載進度和「停止」按鈕在「設定 → 懸浮窗」。需要開啟網路功能。
  - 繪師：ZipZipPipe。DeepSeek 娘原創角色：上善无形（CC BY-NC-SA 4.0）。
- **Windows：Antigravity**（#57）：自動找到 T3 Code 存放的 Antigravity 對話，不必再逐一加入資料夾。
- **Windows：檢查更新**（#59）：GitHub API 因請求過多拒絕時，改從 GitHub 公開的發佈頁取得最新版本，不再顯示「無法連接到 GitHub」。

**修正**
- **macOS 右鍵選單**：懸浮窗偶爾按右鍵沒有反應（每種樣式都會發生），現在選單一關閉，懸浮窗就會立刻恢復接收滑鼠點擊。

**简体中文**
- **AI 娘：新的悬浮窗样式「角色」**，macOS、Windows、Linux 都能用。在悬浮窗上右键，选「样式 → 角色」，桌面上就会站着一位 AI 娘跟着速度起舞：越快动作越大，还会换姿势、转身，身边飘着她自己的花瓣或光点。
  - 共 17 位，每家模型一位：Claude、DeepSeek、Gemini、GLM、GPT、Grok、混元、JEV、Kimi、Llama、MiniMax、Mistral、Perplexity、Qwen、RWKV、Seed、文心。默认跟着这个悬浮窗当前最快的模型换人，也可以在右键「角色」固定一位。
  - 信息卡片浮在她身旁，不会被她挡住：速度在右边；性能与思考速度、网络速度、费用、今日用量与 agent 在左边。每张卡片都能在右键「显示信息」或「设置 → 悬浮窗」开关；最快的模型名称默认不显示。
  - 切换到角色样式时，会从 GitHub 依次自动下载全部角色（共约 160 MB），每一位都先核对大小与 SHA-256 才安装。移除或取消的角色不会再自动下载；下载进度和「停止」按钮在「设置 → 悬浮窗」。需要开启网络功能。
  - 画师：ZipZipPipe。DeepSeek 娘原创角色：上善无形（CC BY-NC-SA 4.0）。
- **Windows：Antigravity**（#57）：自动找到 T3 Code 存放的 Antigravity 对话，不必再逐个添加文件夹。
- **Windows：检查更新**（#59）：GitHub API 因请求过多拒绝时，改从 GitHub 公开的发布页获取最新版本，不再显示「无法连接到 GitHub」。

**修复**
- **macOS 右键菜单**：悬浮窗偶尔右键没有反应（每种样式都会发生），现在菜单一关闭，悬浮窗就会立刻恢复接收鼠标点击。

**English**
- **AI characters: a new orb style, *Character*,** on macOS, Windows and Linux. Right-click an orb and choose Style → Character: an AI character stands on your desktop and dances to the speed — the faster it goes, the bigger she moves, changing poses, turning, with her own petals or sparks around her.
  - 17 characters, one per model maker: Claude, DeepSeek, Gemini, GLM, GPT, Grok, Hunyuan, JEV, Kimi, Llama, MiniMax, Mistral, Perplexity, Qwen, RWKV, Seed and Wenxin. By default she follows the orb's fastest model; right-click → Character keeps one.
  - Readout cards float beside her, never hidden behind her: the speed on her right; Performance and Thinking Speed, Network Speed, Cost, and Today & Agents on her left. Each card switches on or off under right-click → Readouts or Settings → Floating Orb; the fastest model's name is off by default.
  - Switching to the style downloads every character from GitHub one at a time (about 160 MB in all); each is checked against its size and SHA-256 before it is installed. Characters you remove or cancel are not downloaded again; progress and Stop are in Settings → Floating Orb. Network features must be on.
  - Art by ZipZipPipe. DeepSeek-chan's original character by 上善无形 (CC BY-NC-SA 4.0).
- **Windows: Antigravity** (#57): T3 Code's Antigravity conversations are found automatically, with no folder to add per instance.
- **Windows: update checks** (#59): when the GitHub API turns the check away for too many requests, the app reads the latest version from GitHub's public release page instead of reporting that GitHub is unreachable.

**Fixes**
- **macOS right-click menu**: an orb sometimes ignored a right-click (in every style). Orbs now take clicks again as soon as a menu closes.

**日本語**
- **AI キャラクター：新しいオーブスタイル「キャラクター」**。macOS、Windows、Linux で使えます。オーブを右クリックして「スタイル → キャラクター」を選ぶと、デスクトップに AI キャラクターが立ち、速度に合わせて踊ります。速いほど動きが大きくなり、ポーズを変えたり振り向いたりし、周りには彼女だけの花びらや光が舞います。
  - 全 17 人、モデルの開発元ごとに 1 人：Claude、DeepSeek、Gemini、GLM、GPT、Grok、混元、JEV、Kimi、Llama、MiniMax、Mistral、Perplexity、Qwen、RWKV、Seed、文心。既定ではオーブでいちばん速いモデルに合わせて入れ替わり、右クリックの「キャラクター」で 1 人に固定することもできます。
  - 情報カードが彼女のそばに浮かび、彼女に隠れることはありません。速度は右側、性能と思考速度、ネットワーク速度、費用、今日の使用量と agent は左側です。各カードは右クリックの「表示する情報」または「設定 → フローティングオーブ」でオン・オフでき、いちばん速いモデルの名前は既定で非表示です。
  - このスタイルに切り替えると、GitHub から全キャラクターを 1 人ずつ自動でダウンロードします（合計約 160 MB）。それぞれサイズと SHA-256 を確認してからインストールします。削除やキャンセルしたキャラクターは再びダウンロードされません。進行状況と「停止」は「設定 → フローティングオーブ」にあります。ネットワーク機能をオンにする必要があります。
  - イラスト：ZipZipPipe。DeepSeek ちゃんの原作キャラクター：上善无形（CC BY-NC-SA 4.0）。
- **Windows：Antigravity**（#57）：T3 Code が保存する Antigravity の会話を自動で見つけます。インスタンスごとにフォルダを追加する必要はありません。
- **Windows：アップデートの確認**（#59）：GitHub API がリクエスト過多で拒否したときは、GitHub の公開リリースページから最新バージョンを取得し、「GitHub に接続できません」と表示しなくなりました。

**修正**
- **macOS の右クリックメニュー**：オーブを右クリックしても反応しないことがありました（どのスタイルでも）。メニューを閉じるとすぐに、オーブがクリックを受け付けるようになりました。
