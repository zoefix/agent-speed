## What's new / 更新內容

**繁體中文**
- **新來源：Qoder IDE 與 Qoder CLI**（#47），macOS、Windows、Linux 都支援，國際版和國內版都包括。
  - **Qoder IDE**：讀取 IDE 本機的對話資料庫（只讀），每次模型呼叫都有 Qoder 回報的真實 token，所以看得到速度、用量和工作階段。Qoder 沒有記錄請求的開始時間，耗時從上一筆紀錄算起，速度會比模型實際的略低；Qoder 只記錄選用的檔位（Auto、Lite 等），不記實際模型，所以費用顯示「–」。
  - **Qoder CLI**（`qodercli`、國內版 `qoderclicn`，新的 Qoder 桌面 App 也寫在同一處）：使用 Qoder 自家的模型時，Qoder 不會把 token 存到本機，只看得到工作階段和狀態。以 `QODER_EXPOSE_TOKEN_USAGE=1`（國內版 `QODERCN_EXPOSE_TOKEN_USAGE=1`）啟動，或使用自訂模型，才會有 token 和速度。
- **價格**：Grok Build 的 `grok-4.7-build` 等型號依 xAI 官方 API 價格計費（#60）；Claude Fable 5.2 與 Mythos 5.2 依 Anthropic 官方價格計費。價格表每天自動更新，舊版本也已生效。

**修正**
- **macOS 右鍵選單**：把懸浮窗拖到另一台螢幕後，右鍵選單有時再也不出現，懸浮窗甚至會消失，必須重開 App 才恢復。現在選單不再掛在懸浮窗上，任何螢幕都能正常打開，懸浮窗也不會被帶走。選單靠近螢幕邊緣時會往上、往左移，完整顯示。
- **macOS 拖動懸浮窗**：第一次按下拖動有時沒反應，要按第二次才拖得動。現在第一次就能拖。

**简体中文**
- **新来源：Qoder IDE 与 Qoder CLI**（#47），macOS、Windows、Linux 都支持，国际版和国内版都包括。
  - **Qoder IDE**：读取 IDE 本机的对话数据库（只读），每次模型调用都有 Qoder 回报的真实 token，所以能看到速度、用量和会话。Qoder 没有记录请求的开始时间，耗时从上一条记录算起，速度会比模型实际的略低；Qoder 只记录所选的档位（Auto、Lite 等），不记实际模型，所以费用显示「–」。
  - **Qoder CLI**（`qodercli`、国内版 `qoderclicn`，新的 Qoder 桌面 App 也写在同一处）：使用 Qoder 自家的模型时，Qoder 不会把 token 存到本机，只能看到会话和状态。以 `QODER_EXPOSE_TOKEN_USAGE=1`（国内版 `QODERCN_EXPOSE_TOKEN_USAGE=1`）启动，或使用自定义模型，才会有 token 和速度。
- **价格**：Grok Build 的 `grok-4.7-build` 等型号按 xAI 官方 API 价格计费（#60）；Claude Fable 5.2 与 Mythos 5.2 按 Anthropic 官方价格计费。价格表每天自动更新，旧版本也已生效。

**修复**
- **macOS 右键菜单**：把悬浮窗拖到另一台屏幕后，右键菜单有时再也不出现，悬浮窗甚至会消失，必须重开 App 才恢复。现在菜单不再挂在悬浮窗上，任何屏幕都能正常打开，悬浮窗也不会被带走。菜单靠近屏幕边缘时会往上、往左移，完整显示。
- **macOS 拖动悬浮窗**：第一次按下拖动有时没反应，要按第二次才拖得动。现在第一次就能拖。

**English**
- **New sources: Qoder IDE and Qoder CLI** (#47) on macOS, Windows and Linux, international and China editions.
  - **Qoder IDE**: Agent Speed reads the IDE's local chat database (read-only), which holds the tokens Qoder reported for every model call, so speed, usage and sessions show. Qoder stores no request start, so a call is timed from the previous record and speeds read a little lower than the model's; it records only the tier you chose (Auto, Lite, …), not the model, so cost shows "–".
  - **Qoder CLI** (`qodercli`, the China edition's `qoderclicn`; the new Qoder desktop app writes to the same place): with Qoder's own models, Qoder keeps no token usage on disk, so only sessions and status show. Start it with `QODER_EXPOSE_TOKEN_USAGE=1` (China edition: `QODERCN_EXPOSE_TOKEN_USAGE=1`), or use a custom model, to get tokens and speed.
- **Prices**: Grok Build's `grok-4.7-build` and its siblings are priced as xAI's API models (#60); Claude Fable 5.2 and Mythos 5.2 at Anthropic's official prices. The price table updates itself daily, so earlier versions already have them.

**Fixes**
- **macOS right-click menu**: after an orb was dragged to another display, its right-click menu could stop appearing, and the orb could even disappear until the app restarted. Menus are no longer attached to the orb, so they open on every display and never take the orb with them. Near a screen edge a menu moves up and left to show whole.
- **macOS orb dragging**: the first press sometimes did not start a drag, and only a second one did. The first press drags now.

**日本語**
- **新しいソース：Qoder IDE と Qoder CLI**（#47）。macOS、Windows、Linux に対応し、国際版と中国版の両方を含みます。
  - **Qoder IDE**：IDE のローカルのチャットデータベースを読み取り専用で読みます。モデル呼び出しごとに Qoder が報告した実際のトークン数があるため、速度・使用量・セッションが表示されます。Qoder はリクエストの開始時刻を記録しないため、所要時間は直前の記録から数え、速度はモデルの実際より少し低めに出ます。Qoder は選んだ段階（Auto、Lite など）だけを記録し、モデル名は記録しないため、費用は「–」と表示されます。
  - **Qoder CLI**（`qodercli`、中国版 `qoderclicn`。新しい Qoder デスクトップアプリも同じ場所に書き込みます）：Qoder 独自のモデルでは、Qoder がトークン使用量をローカルに保存しないため、セッションと状態だけが表示されます。トークンと速度を表示するには `QODER_EXPOSE_TOKEN_USAGE=1`（中国版は `QODERCN_EXPOSE_TOKEN_USAGE=1`）を付けて起動するか、カスタムモデルを使ってください。
- **価格**：Grok Build の `grok-4.7-build` などは xAI の API 価格で計算します（#60）。Claude Fable 5.2 と Mythos 5.2 は Anthropic の公式価格です。価格表は毎日自動で更新されるため、以前のバージョンにもすでに反映されています。

**修正**
- **macOS の右クリックメニュー**：オーブを別のディスプレイへドラッグしたあと、右クリックメニューが出なくなり、オーブが消えてアプリを再起動するまで戻らないことがありました。メニューはオーブに付属しなくなったため、どのディスプレイでも開き、オーブが一緒に消えることもありません。画面の端ではメニューが上や左にずれて全体が表示されます。
- **macOS のオーブのドラッグ**：最初に押したときドラッグが始まらず、2 回目でようやく動くことがありました。最初の 1 回でドラッグできるようになりました。
